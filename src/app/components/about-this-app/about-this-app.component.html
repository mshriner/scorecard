App Info

This project was created by Marshall Shriner.

App Data: All app data is stored locally on your device. Except when checking for feature updates, no network connection is necessary to use this app.

Privacy: This app is hosted on DigitalOcean. For more information, see the DigitalOcean Privacy Policy.

Sources: View the code for this app on GitHub.



Change Log

7/13/2026

  • Added statistics counting holes with 0 putts, 1 putt, 2 putts, and 3+ putts. These are also visible when viewing individual rounds.

7/10/2026

  • Added the ability to see a few stats while viewing individual rounds. After logging putts, Greens in Regulation and Scrambling Success will show at the bottom of the "View/Edit Round" page
  • Adjusted some behavior for sorting in-progress rounds on the "Results" page

6/28/2026

  • Split the "doubles or worse" statistic into "double bogeys" and "triples or worse"
  • Added precision to average strokes on par 3s, par 4s, and par 5s

6/12/2026

  • When adding a new golf course, you can now search for it using an internet connection. This is powered by GolfCourseAPI, so thank you to them for making this API free and accessible!
    • The new search workflow will pull up a short step-by-step process to find the course you are thinking of.
  • Adjusted labels and spacing on the performance graphs, reducing instances where graph labels were being cut off.
  • Accessibility: Throughout most of the app, clicking on a grayed-out / disabled button will now show a hint on why the button is disabled
  • Bugfix: Users lost the ability to enter a newline in the "Notes For Your Round" section. This is resolved.
  • Upgraded underlying libraries for bug fixes and performance improvements

5/3/2026

  • Upgraded to a more modern technique for storing app data locally, eliminating space constraint concerns
  • Upgraded underlying libraries for bug fixes and performance improvements

  • Fixed a bug when importing the same user profile a second time, causing entanglement
  • Fixed a bug when importing a round at a new course, causing the form to misbehave

  • Upgraded underlying libraries for bug fixes and performance improvements

12/1/2025

  • Upgraded underlying libraries for bug fixes and performance improvements

11/11/2025

  • Added stat for total strokes taken across all rounds that satisfy your filter criteria
  • When deleting a course, a dialog will warn if there are any rounds that will be deleted as a result
  • Bug fixes and enhancements to navigation and snackbar messages

11/2/2025

  • Enhancements to performance trend graphs:
    • Trends are available on more statistics:
      • Avg. score
      • Avg. putts
      • Avg. strokes on par 3s, 4s, and 5s
    • Added a togglable regression line to better show the trend in your performance for each stat
  • When you import a round played on a course that matches any already saved to your profile, a new popup will ask if you want to use an already saved course.

10/8/2025

  • You can now share an entire user profile (including courses and rounds) to another device, on the "Switch Profile" page
  • You can now import a user profile (including courses and rounds) from another device, also on the "Switch Profile" page

10/7/2025

  • Added some enhancements to the performance graphs:
    • Made it more apparent which stats you can view in a graph (click on the "Trend" button below a stat)
    • On the graph view, you can click on a data point for a round to view the results of that round
      • Increased the size of the data points slightly to help with touch targets
    • On the graph view, added the option to space rounds evenly vs. space rounds by date. The latter can result in data points getting bunched together if your timeframe is too large

9/29/2025

  • In the "Stats" section, added the ability to see a graph of performance trends over time for certain statistics. As of this release, you can view trends for the following:
    • Greens in Regulation
    • Scrambling Success
    To open up the graph, click on the corresponding statistic

9/20/2025

  • On the "Edit Round" page, implemented a new strokes and putts interface, replacing the (+) and (-) buttons with a pop-up menu:
    • Click on the cell you want to edit -- a menu will pop up with common options
    • If you needed more strokes to finish the hole, hit the "More..." option, which will expand the menu
    You can activate this new experience when editing a round by clicking the settings Settings icon in the top bar and turning on the "New strokes input UI"
  • Fixed an issue with recording putts (in the old interface) where you would need to hit the (+) button and then the (-) button to log a hole with zero putts
  • This app will now follow the general settings on your device for whether to display in light mode or dark mode. You can force the app into light mode or dark mode using the option in the side menu. Please let me know if anything looks off or could be improved!

8/7/2025

  • Added inferred stats:
    • Greens in Regulation (GIR): Reached the green in time to two-putt for par
    • Scrambling Success: Par or better after missing GIR
    (Based only on strokes and putts; unusual cases like putting off the green are not included)
